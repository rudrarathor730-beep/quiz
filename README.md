## Project Overview
An interactive web-based quiz application designed to test foundational computer science and AI development concepts, including large language models, Git commit message conventions, unit testing practices, frontend separation of concerns, and algorithmic time complexity.

## Features
- **Dynamic Question Rendering:** Questions and interactive option buttons are rendered dynamically using JavaScript.
- **Immediate Feedback:** Options are validated upon selection and user score is tracked.
- **Topics Covered:**
  1. Large Language Models (LLM token prediction)
  2. Git commit conventions (type prefixes like feat/fix)
  3. Test-driven development (TDD / unit test failure before fix)
  4. Separation of styling and logic (CSS file structure)
  5. Computational complexity (nested loops and quadratic complexity)

## Project Files
- `index.html` - Application structure and quiz container.
- `style.css` - Responsive layout, quiz card styling, and interactive button states.
- `script.js` - Quiz logic, question bank, score computation, and UI updates.
- `README.md` - Project documentation and student details.

## How to Run
Open `index.html` in any modern web browser to start the quiz.
